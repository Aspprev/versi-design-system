# Release 0.7.3

Preparada em 03/11/2026 para corrigir o bloqueio da publicação da 0.7.2.

A tag v0.7.2 compilou, mas os testes de legibilidade e secondary ainda comparavam
as paletas atualizadas com valores históricos. O job publish foi ignorado na
[execução 40952980778](https://github.com/Aspprev/versi-design-system/actions/runs/40952980778).

`docs/temas-clientes/0.7.2-approved-overrides.json` registra somente as diferenças
computadas entre 0.7.1 e as paletas aprovadas da 0.7.2 para custom2170, custom2133,
custom2178 e custom2140. Inclui papéis semânticos derivados. O helper aplica essas
diferenças somente às chaves já verificadas por cada contrato. As referências
históricas permanecem intactas. Nenhuma diferença em placeholders ou modos de
alto contraste foi encontrada. Os arquivos de produção dos temas não mudaram.

## Enviar a correção

```powershell
git switch -c fix/theme-contracts-0.7.3
git add -- package.json package-lock.json CHANGELOG.md docs/releases/0.7.3.md docs/temas-clientes/0.7.2-approved-overrides.json tests/helpers/theme-role-migration.ts tests/visual/design-system/legibility-distribution.visual.spec.ts tests/visual/design-system/secondary-migration.visual.spec.ts
git diff --cached --stat
git commit -m "fix: alinhar contratos dos temas e preparar 0.7.3"
git push -u origin fix/theme-contracts-0.7.3
```

Abra a [PR](https://github.com/Aspprev/versi-design-system/compare/master...fix/theme-contracts-0.7.3?expand=1), aguarde os checks e faça o merge.

## Após o merge

```powershell
git switch master
git pull --ff-only origin master
npm run check:release -- v0.7.3
if ($LASTEXITCODE -ne 0) { throw "Versão divergente; não enviar a tag." }
git tag -a v0.7.3 -m "Release 0.7.3"
git push origin v0.7.3
```

O push da branch aciona as validações; o push da tag aciona Publish package nas
[Actions](https://github.com/Aspprev/versi-design-system/actions). Não mover nem
reexecutar a tag v0.7.2 para aplicar esta correção. Nenhuma ação remota foi
executada pelo agente.

## Validação local

- Build, lint sem avisos, TypeScript e check:release v0.7.3 aprovados.
- Os três cenários que bloquearam a publicação passaram (legibilidade desktop e secondary desktop/celular). A duplicata móvel da matriz de legibilidade permanece ignorada conforme a configuração existente.
- A matriz completa será executada pelas Actions no push/PR e na tag.
