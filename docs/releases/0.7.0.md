# Preparação da 0.7.0

> Histórico: PR #36 mesclada e tag v0.7.0 enviada. A publicação foi bloqueada pelo alerta de segurança do Storybook. Não repita os comandos abaixo; siga [a correção 0.7.1](0.7.1.md).

Versão local: `0.7.0`. Base de trabalho: `master`. A tag de publicação será `v0.7.0`, criada somente após o merge da PR. Este guia não afirma que houve commit, push, merge ou publicação.

A versão inclui a migração incompatível de tertiary cromático para secondary, success no Button, listas com seções, limites de seleção, painel flutuante do SelectMulti, contrato de ilustrações e correções de contraste. Leia [o changelog](../../CHANGELOG.md) e [a migração](../migrations/0.7.0-secondary.md) antes de atualizar o consumidor. A comparação da primária custom2133 é somente uma prévia no Storybook.

## Commit e PR — PowerShell, na pasta do DS

```powershell
git switch -c release/0.7.0
git add .
git commit -m "feat: preparar release 0.7.0"
git push -u origin release/0.7.0
```

Abra a [PR para master](https://github.com/Aspprev/versi-design-system/compare/master...release/0.7.0?expand=1), aguarde os checks e faça o merge. Se a PR já existir, use a mesma.

## Tag — depois do merge

```powershell
git switch master
git pull --ff-only origin master
npm run check:release -- v0.7.0
if ($LASTEXITCODE -ne 0) { throw "Versão divergente; não enviar a tag." }
git tag -a v0.7.0 -m "Release 0.7.0"
git push origin v0.7.0
```

O push da tag aciona `publish.yml`, que valida o código e publica o artefato no npm. Acompanhe [GitHub Actions](https://github.com/Aspprev/versi-design-system/actions). Não é necessário executar npm publish localmente. Uma tag já enviada não deve ser recriada ou movida.

## Consumidor — somente após a publicação concluir

Na pasta do projeto consumidor:

```powershell
npm install @aspprev/versi-ds@0.7.0
```

Migre props/tokens tertiary para secondary e revise os usos do secondary antigo. Ao adotar o contrato de ilustrações, retire os overrides temporários correspondentes conforme [a documentação](../illustrations/README.md).

## Conferência local

Manifestos/tag, build do pacote, divisão dos bundles, orçamento de tamanho e conteúdo empacotado passaram. O pacote contém 9 entrypoints, 250 bandeiras e 337 arquivos, restritos aos arquivos de distribuição permitidos.

O Storybook gerou os arquivos estáticos e passou na navegação (351 entradas e 49 componentes). Ao encerrar o build, o Node 24.14.0 no Windows apresentou a asserção `UV_HANDLE_CLOSING`; portanto o comando não encerrou com código zero, apesar da geração concluída. A validação do CI continua necessária antes do merge e da publicação.
