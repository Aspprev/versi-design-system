# Release 0.7.4

Preparada em 03/11/2026. Correção do bloqueio de segurança da tag v0.7.3.

## Correção

- `glob` fixado em `14.0.2` e `minimatch` em `11.0.1` nos overrides do DS.
- Lockfile atualizado; versões principais exigem validar Storybook e ESLint.
- As dependências são transitivas das ferramentas de desenvolvimento. Nenhum
  componente, tema, placeholder ou contrato público foi modificado nesta correção.
- Auditoria continua obrigatória e sem exceções para os alertas.

Referências: [glob](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4) e
[minimatch](https://github.com/advisories/GHSA-g3hv-75wg-m249).
A [execução da 0.7.3](https://github.com/Aspprev/versi-design-system/actions/runs/41650244533)
compilou, mas foi interrompida na auditoria antes de publicar. Não mover a tag antiga.

## Envio, após revisar a validação

```powershell
git switch -c fix/build-security-0.7.4
git add -- package.json package-lock.json CHANGELOG.md docs/releases/0.7.4.md examples/pilot/package.json examples/pilot/package-lock.json
git diff --cached --stat
git commit -m "fix: corrigir glob e minimatch e preparar 0.7.4"
git push -u origin fix/build-security-0.7.4
```

Abra a [PR para master](https://github.com/Aspprev/versi-design-system/compare/master...fix/build-security-0.7.4?expand=1), aguarde os checks e faça o merge.

Depois do merge:

```powershell
git switch master
git pull --ff-only origin master
npm run check:release -- v0.7.4
if ($LASTEXITCODE -ne 0) { throw "Versão divergente; não enviar a tag." }
git tag -a v0.7.4 -m "Release 0.7.4"
git push origin v0.7.4
```

A branch aciona as validações; a tag aciona Publish package nas
[Actions](https://github.com/Aspprev/versi-design-system/actions).
Nenhum commit, push ou tag foi executado pelo agente.
