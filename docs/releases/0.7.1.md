# Correção de segurança — 0.7.1

A tag v0.7.0 foi enviada após o merge da PR #36, mas a [Action](https://github.com/Aspprev/versi-design-system/actions/runs/39665302690) falhou em check:security e ignorou o job publish. Storybook 10.6.0 apresentava o alerta crítico [GHSA-f2ph-cmg5-wxc8](https://github.com/advisories/GHSA-f2ph-cmg5-wxc8). Produção e piloto passaram sem alertas nesse diagnóstico.

A 0.7.1 atualiza os quatro pacotes diretos do Storybook para 10.6.3 e inclui os ajustes funcionais da 0.7.0. A auditoria continua obrigatória. Não mova a tag v0.7.0 e não reexecute a publicação antiga esperando aplicar o novo commit.

## Commit e PR — na pasta do DS

```powershell
git switch -c fix/storybook-security-0.7.1
git add package.json package-lock.json CHANGELOG.md docs/releases/0.7.0.md docs/releases/0.7.1.md
git commit -m "fix: atualizar Storybook e preparar 0.7.1"
git push -u origin fix/storybook-security-0.7.1
```

Abra a [PR para master](https://github.com/Aspprev/versi-design-system/compare/master...fix/storybook-security-0.7.1?expand=1), aguarde os checks e faça o merge.

## Depois do merge

```powershell
git switch master
git pull --ff-only origin master
npm run check:release -- v0.7.1
if ($LASTEXITCODE -ne 0) { throw "Versão divergente; não enviar a tag." }
git tag -a v0.7.1 -m "Release 0.7.1"
git push origin v0.7.1
```

A tag aciona publish.yml. Aguarde o job publish concluir nas [Actions](https://github.com/Aspprev/versi-design-system/actions); então, na pasta do consumidor:

```powershell
npm install @aspprev/versi-ds@0.7.1
```

A migração cromática de tertiary para secondary continua necessária: veja [o guia](../migrations/0.7.0-secondary.md).

Validação local: as quatro auditorias (DS/piloto, completas/produção) passaram com zero alertas; check:release v0.7.1, TypeScript do Storybook, build do Storybook e navegação de 351 entradas/49 componentes passaram. Nenhum commit, push ou tag foi executado pelo agente.
