# Release 0.7.2

Preparada em 29/10/2026. Versão publicada consultada no npm: 0.7.1.

Inclui as paletas aprovadas de custom2170, custom2133, custom2178 e custom2140,
o gradiente decorativo de custom2133, os neutros #212421 de custom2140 e os
contornos de foco por teclado. O Storybook monta FocusNavigationMode globalmente;
consumidores devem montar esse componente no layout para distinguir teclado de
mouse/toque. Placeholders e alto contraste dos temas permanecem preservados.

Também inclui o isolamento de react-number-format no build e os testes de
consumidores webpack, conforme [a nota de empacotamento](../EMPACOTAMENTO-PEERS-OPCIONAIS.md).
Vitest foi atualizado para 4.1.12 e Zod para 4.6.7 no lockfile para remover os
alertas encontrados durante a preparação. Nenhuma API pública foi removida.

## Commit e PR — na pasta do DS

```powershell
git switch -c release/0.7.2
git add -- .storybook/preview.tsx CHANGELOG.md package.json package-lock.json docs scripts/build.mjs scripts/check-bundle-splitting.mjs scripts/test-package.mjs src/components/file-upload/FileDropzone.tsx src/components/focus-navigation/FocusNavigationMode.tsx src/styles.css src/themes.css stories/themes/BrandAccentExamples.tsx tests/visual/design-system/focus.visual.spec.ts tests/visual/design-system/brand-accents.visual.spec.ts tokens
git diff --cached --stat
git commit -m "fix: atualizar temas e foco e preparar 0.7.2"
git push -u origin release/0.7.2
```

Abra a [PR para master](https://github.com/Aspprev/versi-design-system/compare/master...release/0.7.2?expand=1), aguarde os checks e faça o merge.

## Depois do merge

```powershell
git switch master
git pull --ff-only origin master
npm run check:release -- v0.7.2
if ($LASTEXITCODE -ne 0) { throw "Versão divergente; não enviar a tag." }
git tag -a v0.7.2 -m "Release 0.7.2"
git push origin v0.7.2
```

A tag aciona a publicação pelas [Actions](https://github.com/Aspprev/versi-design-system/actions).
Após o job publish concluir, na pasta do consumidor:

```powershell
npm install @aspprev/versi-ds@0.7.2
```

O agente não executou commit, push, PR, tag ou publicação.
