## O que é o VERSI?

O VERSI é o Design System utilizado para padronizar suas interfaces. Ele combina componentes React, tokens CSS, temas, utilitários, hooks e orientações de acessibilidade.

O Storybook é a documentação visual principal: use a barra de ferramentas para comparar temas, contraste, escala de fonte e movimento reduzido; use o painel **Controls** para experimentar as APIs dos componentes.

## Princípios

- Prefira tokens semânticos a valores visuais hardcoded.
- Reutilize componentes existentes antes de criar uma composição nova.
- Mantenha nomes, foco visível, estados de erro e suporte a teclado.
- Ao criar ou alterar um componente, mantenha sua story e tipagem atualizadas.
